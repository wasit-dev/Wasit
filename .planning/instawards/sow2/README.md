# Instawards SOW 2 planning

Tracks Wasit's progress against the second Instaward statement of work (SOW 2):
deliverables, evidence and the week-by-week review. It is written for the Chapter
Lead and the reviewers checking the SOW against what was actually built, and it
follows the layout of `../sow1/`.

**Start at `STATUS.md`.** It has the weekly review table (click a link to see the
proof of a week), the key facts, the SOW deliverables, the job board, the open
items and the session log. Each numbered file is one job, with its goal, its
acceptance criteria and a `Result` section filled in as the job progresses.
`07-evidence-submission.md` maps every SOW evidence row to its proof.

`week-1/copies/` holds text copies of the pull request comments and job logs that
the live links show, for a reviewer who cannot open the example project while it is
private. The live link is the authoritative one.

Marks used everywhere: ✅ built and shown in a real run or a public page · 🟡 built
and tested, or shown only in part · ⬜ planned for a later week.

Nothing here is meant to be polished prose. It is a working checklist, updated in
place, so status can be trusted at a glance.
