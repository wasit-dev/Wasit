## Goal

A demo mode that shows Wasit's checks against a bundled paywall, with no wallet,
key or project. Guides: pointing Wasit at your own x402 or MPP service; setting up
the payer secret (test network by default); the capped opt-in, its caps, and the
fact that the builder's own facilitator receives the deliberately invalid
payments; steps for Windows (PowerShell); a page that states what a PASS proves
and what it does not; and a guide for testing a paying agent with Wasit's
misbehaving test paywall. Install-time guarantees stated in SECURITY.md (no
install scripts, no telemetry, secrets read only from the environment, the
destructive tool behind an explicit opt-in, and the opt-in rules), a software bill
of materials published with the release, and pinned versions in the MCP setup
examples.
